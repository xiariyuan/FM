# MOT20 M23-45 / M23-46 verified results (2026-07-19)

## Objective and protocol

The deployable target remains strict sequence-LOSO: independently train and freeze one outer-held tracker for each of MOT20-01, MOT20-02, MOT20-03, and MOT20-05, concatenate the four tracker files, and run official TrackEval once. The acceptance criterion is COMBINED HOTA > 80.

Teacher/oracle results below are capacity diagnostics only. They are marked `deployable=false`, cannot be submitted, and cannot be mixed with strict OOF results. For every strict fold, the outer-held label file and GT were not read before tracker freeze.

## Strict deployable baseline materialization

The frozen M23-39 outer policy and GT-free outer predictions were used to reconstruct the applied graph for each sequence. All four regenerated tracker files are byte-identical to the original M23-39 strict outer trackers.

## M23-45 first student

M23-45 used a probability ensemble plus gain/loss heads and selected policies by the worst inner-fold exact HOTA delta. On outer-M05 every non-zero policy degraded at least one inner sequence, so the frozen policy was no-op.

Strict outer-M05 result:

- HOTA: 79.732850
- DetA: 81.954850
- AssA: 77.612920
- IDSW: 478
- selected cuts: 0

The robust no-op fallback prevented regression, but this model did not recover teacher capacity.

## M23-46 pure low-capacity student

A low-capacity model search found that a single five-leaf `HistGradientBoostingClassifier`, without probability blending or magnitude regression, produced positive top-1 and top-2 actions on all three outer-training sequences for the outer-M05 experiment.

## Next structural direction

The next capacity experiment must add an action that is not representable as a single source-edge cut or a cross-track replacement:

1. select two temporally compatible source boundaries;
2. cut both selected source edges;
3. swap or cross-reconnect the two suffixes;
4. enforce one-to-one, time-direction, and acyclic constraints;
5. construct the shortlist entirely without GT;
6. use exact HOTA teacher only after shortlist freeze.

This two-boundary 2-opt/suffix-swap action should first be evaluated as `deployable=false` capacity on the strict M23-46/M23-39 baseline graphs. A strict student should be developed only if the official four-sequence teacher capacity materially exceeds the current 79.275400 source-cut ceiling and has a credible path toward 80.
